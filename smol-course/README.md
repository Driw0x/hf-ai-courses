# Hugging Face a smol course

Notes, exercices et expérimentations réalisés dans le cadre de
[Hugging Face a smol course](https://huggingface.co/learn/smol-course).

---

## Objectifs

Ce cours est consacré à l'adaptation et au **fine-tuning des modèles**.

L'objectif est de passer progressivement de l'utilisation d'un modèle existant à son adaptation pour une tâche ou un comportement spécifique.

---

## Progression

### Passage 1 — Fine-tuning et alignment

- [ ] Unit 0 — Onboarding
- [ ] Unit 1 — Instruction Tuning
- [ ] Unit 2 — Evaluation
- [ ] Unit 3 — Preference Alignment
- [ ] Unit 4 — Vision Language Models

Après cette première partie, retour possible au **Agents Course** pour étudier la Bonus Unit consacrée au fine-tuning d'un LLM pour le function calling.

### Passage 2 — Unités avancées

- [ ] Unit 5 — Reinforcement Learning
- [ ] Unit 6 — Synthetic Data
- [ ] Unit 7 — Award Ceremony

Ces unités seront abordées lorsqu'elles seront disponibles, après les bases de fine-tuning et de reinforcement learning nécessaires au reste du parcours.

---

## Sujets principaux

- instruction tuning ;
- Supervised Fine-Tuning (`SFT`) ;
- chat templates ;
- préparation de datasets ;
- évaluation ;
- preference alignment ;
- DPO ;
- modèles multimodaux ;
- reinforcement learning pour les LLM ;
- données synthétiques.
