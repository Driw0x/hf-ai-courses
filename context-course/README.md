# Hugging Face Context Course

Notes, exercices et expérimentations réalisés dans le cadre du
[Hugging Face Context Course](https://huggingface.co/learn/context-course).

---

## Objectifs

Ce cours est consacré au **context engineering pour les agents de code**.

L'objectif est d'apprendre à structurer et fournir efficacement les informations dont un agent a besoin, puis à connecter des outils et coordonner plusieurs composants agentiques.

---

## Progression

Le cours peut être suivi de manière continue après le Agents Course :

- [ ] Unit 0 — Onboarding
- [ ] Unit 1 — Agent Skills
- [ ] Unit 2 — Model Context Protocol
- [ ] Unit 3 — Plugins
- [ ] Unit 4 — Sub-agents
- [ ] Unit 5 — Hooks
- [ ] Unit 6 — Bonus: Nano Harness

Les Units 0 à 5 constituent le cœur du cours. L'Unit 6 complète le parcours en montrant comment construire une boucle d'agent minimale depuis zéro.
