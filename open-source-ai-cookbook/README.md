# Hugging Face Open-Source AI Cookbook

Notebooks et expérimentations réalisés à partir du
[Hugging Face Open-Source AI Cookbook](https://huggingface.co/learn/cookbook).

---

## Objectif

Le **Open-Source AI Cookbook** est utilisé comme ressource complémentaire plutôt que comme un cours linéaire.

Les notebooks sont consultés et reproduits en fonction des besoins rencontrés dans les autres cours ou dans mes projets personnels.

---

## Utilisation

Les ressources pourront notamment être utilisées pour approfondir :

- RAG ;
- embeddings ;
- inference ;
- fine-tuning ;
- évaluation des LLM ;
- LLM-as-a-Judge ;
- GRPO ;
- optimisation ;
- workflows utilisant des modèles open source.

Il n'y a pas de progression imposée : les notebooks sont sélectionnés au fur et à mesure des besoins.

---

## Structure du dossier

La structure sera ajoutée uniquement lorsque des notebooks ou expérimentations du Cookbook seront intégrés au dépôt.
