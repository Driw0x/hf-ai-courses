# Hugging Face LLM Course

Notes, exercices et expérimentations réalisés dans le cadre du
[Hugging Face LLM Course](https://huggingface.co/learn/llm-course).

---

## Objectifs

Ce cours permet d'approfondir le fonctionnement des **Large Language Models**, des architectures **Transformer** et des principales bibliothèques de l'écosystème Hugging Face.

L'objectif est notamment de mieux comprendre ce qui se passe derrière :

```python
model.generate(...)
```

et derrière les appels effectués par les frameworks d'agents.

---

## Progression

Le cours est suivi en plusieurs passages afin d'alterner théorie et mise en pratique dans les autres cours.

Ce dernier chapitre sera abordé après avoir acquis davantage de bases en **reinforcement learning**, afin de mieux comprendre les méthodes utilisées pour entraîner des modèles de raisonnement.
